# M157 — Unified User Experience

## Purpose
Desktop stops exposing systems. Users think in workflows instead of subsystems. Replace subsystem thinking with experience thinking.

## Experience-First Navigation
| Instead of | Present |
|---|---|
| Knowledge, Timeline, Reports | Understand Project |
| Planner, Reasoning, Explorer | Review Architecture |
| AI, Providers, Router | Continue Previous Work |
| Agents, Tasks, Conversations | Investigate Problem |
| Settings, Storage, Audit | Improve Repository |

## Desktop Evolution
### Workspace Memory
- Remember last screen, panel layout, search history
- Per-project layout persistence

### Activity Center
- Centralized engineering notifications
- Background job progress
- Task progress tracking

### Engineering Console
- Unified command interface
- Real-time system status
- Quick action shortcuts

## Integration
- All screens remain backward-compatible
- New experience-first navigation layer on top
- Keyboard-first, visually clean
