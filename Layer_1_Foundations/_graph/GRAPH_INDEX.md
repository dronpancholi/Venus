# PROJECT VENUS — LAYER 1: KNOWLEDGE GRAPH

**Purpose**: Machine-readable graph of all Venus entities and their relationships. Enables impact analysis, traceability, and autonomous navigation.

---

## Node Types

| Type | Description | Source Directory |
|------|-------------|-----------------|
| `part` | Knowledge domain component | `*_parts/`, `*_modules/` |
| `engine` | Executable/verification module | `*_parts/` (Engine_ prefix) |
| `template` | Output artifact blueprint | `*_templates/` |
| `stage` | Process stage | `stages/` |
| `certificate` | Certification artifact | `*_templates/` (Certificate_ prefix) |
| `schema` | Canonical schema | `Layer_1/_schemas/` |
| `constitution` | Constitutional rule | `Layer_5/` |
| `os_version` | Operating system version | `Layer_2/` root |

## Edge Types

| Type | Description |
|------|-------------|
| `depends_on` | Source requires target |
| `references` | Source references target |
| `inherits` | Source inherits from target |
| `produces` | Engine produces template/certificate |
| `validates` | Engine validates part/template |
| `contains` | OS version contains part/engine/template |
| `extends` | Schema extends base schema |

---

## Graph Files

| File | Format | Purpose |
|------|--------|---------|
| `graph.nodes.json` | JSON | All nodes with type, layer, version |
| `graph.edges.json` | JSON | All typed edges |
| `graph.cypher` | Cypher | Import script for Neo4j/ArangoDB |

---

## Graph Construction

The graph is generated by `_validation/generate_catalog.py` which:
1. Scans all `Layer_*` directories
2. Extracts metadata from file headers and directory structure
3. Resolves cross-references from markdown links
4. Outputs `catalog.json`, `dependency_graph.json`, `graph.nodes.json`, and `graph.edges.json`
