# Part 07 — Competitive Intelligence

## 1. Context & Strategy
Competitive Intelligence details competitor features, architectures, funding levels, GTM channels, pricing models, and strategic weak spots to design an architectural and commercial moat.

---

## 2. Competitive Matrix Schema

| Competitor Name | Funding Tier | Pricing Model | Primary Technical Weakness | Core Moat | Our Attack Vector |
|---|---|---|---|---|---|
| **[Competitor A]** | VC Funded | Seat-based SaaS | High latency on bulk query runs | First mover brand | Lower cost, faster API routes |
| **[Competitor B]** | Bootstrapped | Usage-based | Lacks enterprise SOC2 compliance | Niche features | Full SOC2 + enterprise SLAs |

---

## 3. Moat Assessment Taxonomy
*   **System Moat**: Unique data network effects.
*   **IP Moat**: Patentable scheduling or execution algorithms.
*   **Switching Cost Moat**: Deep database schema integration.

---

## 4. Competitive Intelligence Checklist
*   [ ] Conducted competitor feature gap audits.
*   [ ] Checked competitor pricing tiers.
*   [ ] Mapped competitor technical vulnerabilities.
*   [ ] Defined project's primary competitive moat.
