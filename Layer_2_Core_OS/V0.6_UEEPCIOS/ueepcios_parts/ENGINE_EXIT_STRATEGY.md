# Engine: Exit Strategy

## 1. Context & Strategy

### 1.1 Purpose
The Exit Strategy Engine models exit timelines, founder returns, strategic fit, and comparable transaction multiples.

### 1.2 Philosophy
Build with an exit in mind. Modeling founder return multipliers ensures we allocate resources to projects that optimize strategic exits.

---

## 2. Exit Return Calculation
The engine projects founder returns over 3 years:

\[Founder\_Exit\_Return = Valuation_{Exit} \times Founder\_Equity\_Share\_Percentage\]

---

## 3. Exit Strategy Checklist & Exit Criteria
*   [ ] Projected Month 36 exit valuations.
*   [ ] Checked comparable exit deals.
*   *Exit Criteria*: Exit Strategy Report certified.
