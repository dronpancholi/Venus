## 2. Mathematical Formulations
Process Efficiency Index ($PEI$) determines the efficiency ratio of a specified process sequence:
$$PEI = \sum_{j=1}^{M} \frac{T_{value\_add, j}}{T_{total, j}} \cdot \left(1 - D_j\right)$$
Where:
- $M$ is the total number of process steps.
- $T_{value\_add, j}$ is the time spent on value-add activities during step $j$.
- $T_{total, j}$ is the total elapsed cycle time of step $j$.
- $D_j \in [0, 1]$ is the defect rate recorded during step $j$.

## 5. Institutional Checklist
This checklist guides the execution life cycle of the engine. All actions must be verified by the executing agent.

### 5.1 Pre-Execution Phase
- Verify that BPMN definition mapping matches active operation steps.
- Query the ERP log database for recent execution timings.
- Clear memory cache for process optimization algorithm.

### 5.2 Execution Phase
- Execute statistical cycle time parsing on process steps.
- Run process logs through validation schema.
- Calculate Process Efficiency Index ($PEI$) for target workflow.

### 5.3 Post-Execution Phase
- Export recommendation file to process design committee.
- Trigger automated updates to workflow task parameters in ERP.
- Record optimized baseline times in registry.

### 5.4 Exception & Rollback Phase
- If PEI is below 0.60, suspend process routing changes.
- Revert workflow task assignments to previous operational baseline.
- Alert COO and Process Engineering Director of process degradation.
