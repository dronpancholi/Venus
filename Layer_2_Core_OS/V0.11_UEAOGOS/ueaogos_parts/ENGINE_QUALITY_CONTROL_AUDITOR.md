## 2. Mathematical Formulations
Process Capability Index ($C_{pk}$) indicates the performance capability of process outputs:
$$C_{pk} = \min \left( \frac{USL - \mu}{3\sigma}, \frac{\mu - LSL}{3\sigma} \right)$$
Where:
- $USL$ is the Upper Specification Limit of the quality target.
- $LSL$ is the Lower Specification Limit of the quality target.
- $\mu$ is the statistical mean of the process samples.
- $\sigma$ is the standard deviation of the process samples.

## 5. Institutional Checklist
This checklist guides the execution life cycle of the engine. All actions must be verified by the executing agent.

### 5.1 Pre-Execution Phase
- Verify calibration status of process sensors.
- Extract sample records from target batches.
- Confirm testing limits match guidelines.

### 5.2 Execution Phase
- Execute statistical calculations on sample measurements.
- Run data checks using QualityAuditPayload schema.
- Calculate the Process Capability Index ($C_{pk}$).

### 5.3 Post-Execution Phase
- Lock verified quality audit logs in system database.
- Flag deviant process batches on inventory systems.
- Export findings to QA manager.

### 5.4 Exception & Rollback Phase
- If Cpk falls below 1.33, trigger process shut down alarms.
- Quarantine the affected batch from inventory.
- Revert process parameters to standard safety defaults.
