## 2. Mathematical Formulations
Case Severity Index ($CSI_{ethics}$) calculates the response and investigation priority:
$$CSI_{ethics} = w_v \cdot V_{violation\_type} + w_p \cdot P_{implicated} + w_m \cdot M_{financial\_impact}$$
Where:
- $V_{violation\_type} \in [1, 10]$ is the ethical violation category severity weight.
- $P_{implicated} \in [1, 10]$ represents the seniority level of the implicated employee.
- $M_{financial\_impact} \in [1, 10]$ represents the magnitude scale of potential corporate losses.
- $w_v, w_p, w_m$ are normalized priority weights where $\sum w = 1.0$.

## 5. Institutional Checklist
This checklist guides the execution life cycle of the engine. All actions must be verified by the executing agent.

### 5.1 Pre-Execution Phase
- Confirm encryption pipelines for whistleblower portals are active.
- Clear memory buffers on case triage nodes.
- Verify active access authorization credentials.

### 5.2 Execution Phase
- Execute classification parsing on incoming case metadata.
- Run data checks using EthicsCasePayload schema.
- Calculate the Case Severity Index ($CSI_{ethics}$).

### 5.3 Post-Execution Phase
- Route case details directly to appropriate compliance investigator.
- Lock metadata records to ensure informant safety.
- Send case confirmation status messages.

### 5.4 Exception & Rollback Phase
- If Chief Executive is implicated, route case directly to Board Audit Committee.
- Lock target access privileges of implicated executives.
- Revert incident review access to air-gapped security state.
