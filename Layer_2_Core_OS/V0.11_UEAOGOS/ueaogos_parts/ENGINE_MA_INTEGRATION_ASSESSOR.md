## 2. Mathematical Formulations
Synergy Realization Score ($SRS$) indicates post-merger alignment success:
$$SRS = \sum_{s=1}^{S} w_s \cdot \frac{C_{achieved, s}}{C_{target, s}} \cdot \left(1 - \theta_{friction}\right)$$
Where:
- $S$ is the number of integration milestones.
- $C_{achieved, s}$ is the synergy cost savings achieved for metric $s$.
- $C_{target, s}$ is the target synergy objective.
- $w_s$ is the weight of target milestone $s$.
- $\theta_{friction} \in [0, 0.5]$ is the cultural and system friction penalty parameter.

## 5. Institutional Checklist
This checklist guides the execution life cycle of the engine. All actions must be verified by the executing agent.

### 5.1 Pre-Execution Phase
- Collect consolidation progress data from joint integration groups.
- Verify active system migration paths.
- Run data check on financial consolidation accounts.

### 5.2 Execution Phase
- Execute financial auditing calculations on savings categories.
- Run data checks using MaIntegrationPayload schema validator.
- Calculate the Synergy Realization Score ($SRS$).

### 5.3 Post-Execution Phase
- Deliver M&A advisory dashboard reports to Board.
- Adjust post-merger integration timelines where required.
- Lock finalized IT migration structures in target registry.

### 5.4 Exception & Rollback Phase
- If SRS drops below 0.70, suspend automated migration activities.
- Isolate target infrastructure and run data isolation checks.
- Revert system settings to pre-migration network architectures.
