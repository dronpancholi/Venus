# Empathy Map Template

## 1. Document Overview
An empathy map is a collaborative tool teams use to gain deeper insight into their customers. By structuring observations across what users Say, Think, Do, and Feel, we align team mental models around actual user experiences and behaviors rather than assumptions.

## 3. Four-Quadrant Empathy Map
Use the structure below to capture observations from interviews, support logs, and user testing sessions.

```

                  |                       THINKS                          |
                  |  - "I hope I don't break the database connection."     |

                  |                           |                           |
```

## 5. Session Facilitation Questions
When running an empathy mapping session with stakeholders or users, use these prompt questions to gather data:

1.  **To uncover thoughts:** *"What are they thinking but might not say out loud when using our product?"*
2.  **To uncover feelings:** *"How does the user feel when they encounter an error screen? What emotions dominate their day?"*
3.  **To uncover pain points:** *"What is the most tedious, frustrating part of their current workflow?"*
4.  **To uncover gains:** *"What success metric is their job performance evaluated on?"*
