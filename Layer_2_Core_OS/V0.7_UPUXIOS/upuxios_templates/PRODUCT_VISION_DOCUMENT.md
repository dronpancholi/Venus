## 4. Horizon Planning (3-Year Roadmap Outlook)
To balance short-term execution with long-term innovation, we organize our roadmap across three horizons.

```
 VALUE/ARR
     ^
     |                                                      [ Horizon 3: Disrupt ]
     |                                                      - New markets
     |                                                      - Blue-ocean tech
     |                                                      - Timeline: 24-36 mo
     |
     |                              [ Horizon 2: Expand ]
     |                              - Adjacent verticals
     |                              - Product extensions
     |                              - Timeline: 12-24 mo
     |
     |      [ Horizon 1: Core ]
     |      - Main value loop
     |      - Polish UX / Scale infra
     |      - Timeline: 0-12 mo
     +---------------------------------------------------------------------------->
                                                                            TIME
```

*   **Horizon 1: Core Value Optimization (0 - 12 Months)**
    *   *Focus:* Build the primary features, eliminate friction in onboarding, and establish the user activation loop.
*   **Horizon 2: Market Expansion (12 - 24 Months)**
    *   *Focus:* Introduce advanced integrations, multi-tenant collaboration, and expand targeting to adjacent ICP verticals.
*   **Horizon 3: Disruptive Innovation (24 - 36 Months)**
    *   *Focus:* AI-driven automation of core tasks, predictive intelligence, and industry ecosystem plays.
